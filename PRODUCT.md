# Product

## Register

product

## Users

General users who want a cleaner, more visual alternative to Chrome's built-in bookmark manager. They save bookmarks across browsing sessions and need to find them again quickly. The primary job is saving, organizing, and retrieving bookmarks with minimal friction.

## Product Purpose

A Chrome extension bookmark manager that makes saving and finding bookmarks effortless. It replaces Chrome's clunky built-in manager with a polished, searchable, visually organized library. Users can tag, collect, pin, and preview bookmarks — then find them instantly via search, tags, or browsing collections.

## Brand Personality

Minimal & Professional. Clean, calm, and purposeful — like Linear, Raycast, or Notion. The tool should disappear into the task. No decorative flourishes, no gratuitous motion. Every element earns its place. Trust through consistency and precision.

## Anti-references

- **Generic admin panel**: No Bootstrap/Material Design default look. No heavy borders, no default blue links, no unstyled form controls.
- **Chrome's built-in bookmark manager**: No dense tree views, no tiny text, no cluttered folder hierarchies without visual differentiation.
- **Over-decorated consumer apps**: No gradients for decoration, no playful illustrations, no onboarding wizards that delay the first action.

## Design Principles

1. **Disappear into the task** — The interface should be invisible when the user is focused. Controls appear when needed, recede when not.
2. **One action, one affordance** — Every interactive element has exactly one clear purpose. No mystery meat navigation.
3. **Consistency is trust** — Same button shape, same spacing rhythm, same interaction patterns everywhere. Users should never pause to parse a component.
4. **Content first, chrome second** — Bookmarks are the product. The UI serves them, not the other way around.
5. **Fast to scan, fast to act** — Visual hierarchy that guides the eye to what matters in under 2 seconds. Common actions are one click away.

## Accessibility & Inclusion

- WCAG 2.1 AA minimum
- All interactive elements have visible focus rings
- Touch targets ≥ 44×44px
- Respect `prefers-reduced-motion`
- Sufficient color contrast (≥4.5:1 for body text)
